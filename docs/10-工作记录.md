## 三、尚需明确的事项

| 事项 | 当前建议 / 已知情况 | 影响 |
|---|---|---|
| 同名与重复上传 | 草案按 UUID 定位，每次上传新建独立记录，同名允许重复 | 需确认是否实际需要更新同一个技能，以及上传重试是否必须幂等 |
| 搜索范围 | 草案只搜名称和简介 | 需确认是否还需要正文、分类和标签筛选 |
| 数据库 | 草案使用 PostgreSQL，讨论也提到 MySQL | 确定实际提供的数据库后再固定驱动及物理 DDL |
| 对象存储 | 使用团队现成服务 | 需要测试 bucket、接入方式及可用的测试访问条件 |
| 网关身份 | 后端记录可信用户 ID | 需要明确字段、唯一性及网关传递规则 |
| 存量和旧接口 | 现有 bundle、页面、安装台账等仍在代码中 | 需要调用方清单与去留结论，不能直接删旧数据或用新 ID 替换旧 ID |

以上事项应记录实际结论及依据，不把本稿建议写成领导已经确认的要求。
