# 后端技术栈要求

编程语言：TypeScript

HTTP框架：Hono - 这里可用hono脚手架生成基础项目结构

ORM框架：Prisma 7.x - prisma 7.x 相比 prisma 6.x，有破坏性的更新，注意不要使用了prisma 6.x的用法

数据库：Pg

Schema校验：Zod

日志：Pino

Redis：ioredis

对象存储：AWS SDK

链路追踪：OpenTelemetry

测试：Vitest

包管理：npm

Lint：ESLint

**多态的约束：禁用class搭配****继承****来实现多态，使用interface搭配组合的方式来实现多态**
