# 背景

- 目前缺一个独立的skill分发入口
    
- innoagent需要一个skill仓库
    

# 需求概述

用户把技能打成 zip 传上来，别人能搜到、能下下来

# 需求点

|   |
|---|
|需求点|
|上传、搜索、详情、下载|
|版本下架、技能下架|
|外部 JWT 验证|
|对象存储放文件|

# 概念

|   |   |
|---|---|
|概念|大白话|
|`owner`|谁传的skill。就是网关给的用户身份，一个字符串|
|`skill`|一个技能，比如 `weather`。是「货架条目」，**本身不含版本**|
|`skill_version`|具体版本，比如 `1.2.0`。**能不能下载看这一层**|
|`skill_file`|版本里每个文件的登记条（路径、大小、sha256）|
|对象存储|真正放文件**字节**的地方（MinIO / S3）|

数据库里一个字节都不存，只存一把钥匙（`storage_key`）。拿钥匙去对象存储换文件。
