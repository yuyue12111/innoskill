## 1. 通用约定

  

### 1.1 前缀与 Base URL

  

统一前缀 `/api`

  

|   |   |
|---|---|
|环境|Base URL|
|本地开发|`http://localhost``:{PORT}`（|
|生产|网关域名|

  

本文中所有路径均以 `/api` 开头，是完整路径。

  

### 1.2 身份

  

平台**不碰用户体系，没有用户表**。请求携带外部签发的 JWT，由网关验签后把身份透传给平台，平台读取网关注入的身份头（`X-User-Id`）。

  

|   |   |
|---|---|
|项|说明|
|传输方式|网关验签后的身份头（`X-User-Id`）。平台自身不解析 JWT|
|身份标识|一个字符串（`owner_id`），全平台唯一身份类型|
|匿名|**合法状态**。不携带身份头即为匿名，搜索 / 详情 / 下载对匿名开放|
|`owner` 来源|**上传**的 owner 只从身份头来，URL 里不写（写两遍就得校验一致，没必要）；**下架**的 URL 里有 `{owner}`，必须与身份头一致，否则 `403`|

  

### 1.3 错误响应

  

所有非 2xx 响应共用一种结构：

  

```JSON
{
  "error": {
    "code": "NOT_FOUND",
    "message": "skill not found: alice/weather",
    "details": {}
  }
}
```

  

|   |   |   |   |
|---|---|---|---|
|字段|类型|必有|说明|
|`error.code`|string|是|机器可读的错误码，见下表|
|`error.message`|string|是|面向人的错误描述，可直接展示|
|`error.details`|object|否|结构化补充信息。目前仅上传校验失败时携带 `warnings[]`|

  

`code` 与 HTTP 状态码的对应关系：

  

|   |   |   |
|---|---|---|
|HTTP|`error.code`|触发场景|
|400|`BAD_REQUEST`|参数非法 / 分页越界 / 包校验失败 / 包超限 / 版本不可下载|
|400|`NOT_FOUND`|技能或版本不存在。**六个接口统一：找不到返回 400，不返回 404**|
|401|`UNAUTHORIZED`|接口要求身份但请求匿名；或匿名携带 `owner=me`|
|403|`FORBIDDEN`|无权：非 owner 的写操作、PRIVATE 或已下架资源的读取|
|429|`RATE_LIMITED`|超过该接口的限流额度|
|500|`INTERNAL`|服务端内部错误|

  

### 1.4 限流

  

超过额度返回 `429 RATE_LIMITED`。匿名与已登录按不同额度计。

  

|   |   |   |   |
|---|---|---|---|
|#|接口|匿名|已登录|
|1|上传|—（必须登录）|10 / 分|
|2|搜索|20 / 分|60 / 分|
|3|详情|不限|不限|
|4|下载|30 / 分|120 / 分|
|5|版本下架|—（必须登录）|10 / 分|
|6|技能下架|—（必须登录）|10 / 分|

  

### 1.5 URL 与命名约定

  

|   |   |
|---|---|
|约定|说明|
|`{owner}`|作者身份标识（`owner_id`），也是 `skill` 表唯一约束的一半|
|`{slug}`|技能短名，由 `SKILL.md` 的 `name` 归一化而来（见 §3.2）|
|`{version}`|版本号字符串，如 `1.2.0`|
|唯一约束|`(owner_id, slug)` —— **同一个 URL 必然对应唯一一条技能记录**|

  

### 1.6 分页

  

`page` 从 `0` 开始，`size` 默认 `20`。**取值范围：****`page ≥ 0`****、****`size ∈ [1,100]`****，越界返回** **`400`****，不静默回落默认值。**

## 3. 上传

  

### 3.1 功能

  

把一个 zip 技能包传上来，**上传成功即发布**，没有扫描态、没有待审态、没有人工看过内容。这是「上传即公开」的自觉取舍（28 §9.1）。

  

服务端依次做：读入内存 → 解包校验 → 解析 `SKILL.md` → 落库 → 写对象存储 → 提交 → **异步重建搜索索引**。

  

**注意最后一环是异步的：返回 201 不代表立刻能搜到**（28 §9.4）。索引滞后期间该技能仍可被详情与下载接口正常访问。

  

```Plain
POST /api/skills
Content-Type: multipart/form-data
X-User-Id: alice
```

  

### 3.2 请求参数

  

表单字段（`multipart/form-data`）：

  

|   |   |   |   |   |
|---|---|---|---|---|
|字段|类型|必填|默认|作用|
|`file`|file|**是**|—|技能包本体，一个 zip。**根目录必须有** **`SKILL.md`**；多套一层文件夹会被自动剥掉；`__MACOSX` / `.DS_Store` / `._*` 会被跳过|
|`visibility`|string|否|`PUBLIC`|技能可见性。`PUBLIC` 所有人可见；`PRIVATE` 仅作者可见。取值见 §9.1|
|`confirmWarnings`|boolean|否|`false`|校验产生 warning 时是否继续。为 `false` 且有 warning → 直接 400，让你先确认|

  

zip 内 `SKILL.md` 的 YAML frontmatter 字段：

  

|   |   |   |   |
|---|---|---|---|
|字段|类型|必填|作用|
|`name`|string|**是**|技能展示名，写入 `skill.display_name`；**同时作为 slug 的生成源**（归一化规则见下）|
|`description`|string|**是**|技能简介，写入 `skill.summary`|
|`version`|string|否|版本号。**省略时服务端自动生成** **`yyyyMMdd.HHmmss`**|

  

**slug 生成规则**：`slug = slugify(name)` —— 去首尾空格 → 转小写 → 非字母数字字符替换为 `-` → 折叠连续 `-` → 去掉首尾 `-`。结果须满足：长度 2–64、不含大写字母、不含 `--`、不在保留字列表内（`admin` / `api` / `me` / `global` / `system` 等）。不满足则 400。

  

### 3.3 返回参数

  

**成功：****`201 Created`**

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`owner`|string|技能归属者，取自身份头|
|`slug`|string|由 `SKILL.md` 的 `name` 生成的技能短名，下载 / 详情 URL 里用它|
|`displayName`|string|技能展示名，来自 `SKILL.md` 的 `name`|
|`summary`|string|技能简介，来自 `SKILL.md` 的 `description`|
|`visibility`|string|落库后的可见性（`PUBLIC` / `PRIVATE`）|
|`version`|string|本次上传产生的版本号。来自 frontmatter，或服务端自动生成|
|`status`|string|**恒为** **`PUBLISHED`**，上传即发布|
|`fileCount`|integer|包内文件数，用于核对与展示|
|`totalSize`|integer|包内文件总字节数|
|`publishedAt`|string|发布时间（ISO 8601 UTC）|
|`warnings`|array|本次校验产生的告警。结构见下。仅在 `confirmWarnings=true` 放行时可能非空|

  

`warnings[]` 元素：

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`code`|string|告警类型，如扩展名不在白名单、内容与扩展名不符、疑似密钥泄露|
|`message`|string|面向人的说明|
|`filePath`|string\|null|触发告警的包内文件路径，无具体文件时为 `null`|

**失败：****`400`**，且校验未通过时 `error.details.warnings[]` 携带完整告警列表（结构与上表相同），供调用方修正后重试。

  

### 3.4 校验与限制

|   |   |
|---|---|
|规则|结果|
|未登录|`401 UNAUTHORIZED`|
|包内文件数 > 100|`400 BAD_REQUEST`|
|单个文件 > 10 MB|`400 BAD_REQUEST`|
|路径逃逸（`../` 跳出包根）|`400 BAD_REQUEST`|
|缺 `SKILL.md`|`400 BAD_REQUEST`|
|`name` 或 `description` 缺失 / 为空|`400 BAD_REQUEST`|
|扩展名不在白名单、magic bytes 与扩展名不符、命中密钥泄露正则|**只产生 warning**；`confirmWarnings=false` 时仍拒绝（400），为 `true` 时放行并回传 `warnings[]`|
|版本号已存在且已发布|`400 BAD_REQUEST`（报错）|
|版本号已存在但已下架|**允许覆盖**，旧版本的产物被替换|

  

### 3.5 副作用

|   |   |
|---|---|
|对象|动作|
|数据库|写 `skill`（find-or-create）、`skill_version`、`skill_file`|
|对象存储|写 N 个单文件（`skills/{skillId}/{versionId}/{包内路径}`）+ 1 个整包（`packages/{skillId}/{versionId}/bundle.zip`）。用户上传的原始 zip 不保留|
|搜索索引|**事务提交后异步重建**，有延迟|

  

**事务边界**：从 `findOrCreate` 到写完 bundle 为一个事务。对象存储不参与事务，写存储失败则数据库回滚。

## 4. 搜索

### 4.1 功能

  

按关键词与作者检索技能，返回分页结果。用 PostgreSQL 全文检索（`tsvector`），中文靠提前分词写入 `search_text` 补偿。

  

**两阶段读**：先查索引确定「哪些 id 命中、按什么顺序」，再按这批 id 回表读真实数据，最后按索引给的顺序重排。由此推出两条语义：

  

- **索引与数据库不一致时以数据库为准** —— 索引只决定「谁能被搜到、排第几」，不决定搜出来的内容。
    
- **`total`** **与** **`items`** **不等** —— 前者是命中总数，后者只是当前页。翻页越界时 `items` 为空而 `total` 不为 0。
    
      
    

```Plain
GET /api/skills?q=天气&owner=alice&sort=newest&page=0&size=20
```

  

### 4.2 请求参数

  

|   |   |   |   |   |
|---|---|---|---|---|
|参数|类型|必填|默认|作用|
|`q`|string|否|无|关键词。留空则不按关键词过滤，只按其他条件筛|
|`owner`|string|否|无|按作者过滤。**传** **`me`** **表示「当前登录用户传的」**；匿名传 `me` → `401`（`me` 的求值依赖身份）|
|`sort`|string|否|`newest`|排序方式：`newest` / `downloads` / `relevance`。非法值 → `400`|
|`page`|integer|否|`0`|页码，从 0 开始。必须 `≥ 0`，否则 `400`|
|`size`|integer|否|`20`|每页条数。必须落在 `[1,100]`，否则 `400`|

  

**可见性过滤**（服务端按请求者身份自动施加，无参数可关）：

  

|   |   |
|---|---|
|请求者|能搜到|
|匿名|仅 `PUBLIC`|
|已登录（未带 `owner`）|`PUBLIC`，加上**自己传的** **`PRIVATE`**|
|已登录（`owner=me`）|自己传的全部，含 `PRIVATE`|

  

**恒不可搜到的**：`hidden = TRUE`（技能级下架）的技能；`status = ARCHIVED` 的技能。任何情况下都搜不到 —— 包括作者本人。

  

> `owner=me` 是必须的参数，没有它作者传完私有技能就再也列不出自己传过什么（27 §3.2 窟窿 ③）。

  

### 4.3 返回参数

  

**成功：****`200 OK`**

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`items`|array|**当前页**的技能条目，结构见下|
|`total`|integer|命中总数，与 `items.length` 不相等|
|`page`|integer|回显页码|
|`size`|integer|回显每页条数|

  

`items[]` 元素：

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`owner`|string|作者身份标识，用于拼详情 / 下载 URL|
|`slug`|string|技能短名，用于拼详情 / 下载 URL|
|`displayName`|string|技能展示名|
|`summary`|string|技能简介|
|`ownerDisplayName`|string|作者的展示名，直接用于列表渲染（来源见 §9.3）|
|`visibility`|string|`PUBLIC` / `PRIVATE`。`PRIVATE` 只可能出现在「自己传的」结果里|
|`downloadCount`|integer|该技能累计下载次数。`sort=downloads` 按它排序|
|`headlineVersion`|string\|null|当前对外版本号，客户端据此拼下载 URL|
|`publishedAt`|string\|null|`headlineVersion` 的发布时间|

  

**搜索结果不含** **`hidden`** **字段** —— 该字段只在详情响应里暴露（07 §5.5）。

  

**错误**：`400`（`sort` / `page` / `size` 非法）、`401`（匿名传 `owner=me`）、`429`。

## 5. 详情

  

### 5.1 功能

  

读单个技能的完整信息，**包含** **`versions[]`** **版本列表**。版本列表是必需的：不告诉客户端有哪些版本，客户端拼不出下载 URL，只能靠猜（27 §3.2 窟窿 ②）。

  

**详情不碰搜索索引**，直接读 `skill` 表 —— 与搜索是两条独立链路。因此**刚上传完的技能，详情立刻可见，搜索可能还搜不到**。

  

```Plain
GET /api/skills/alice/weather
```

  

### 5.2 请求参数

  

**路径参数**（无查询参数）：

  

|   |   |   |   |
|---|---|---|---|
|参数|类型|必填|作用|
|`owner`|string|是|作者身份标识|
|`slug`|string|是|技能短名|

  

**访问控制**：

  

|   |   |
|---|---|
|请求者|结果|
|任何人 + `PUBLIC` 且未下架|`200`|
|作者本人 + `PRIVATE`|`200`|
|非作者 + `PRIVATE`|`403`|
|非作者 + 已被技能级下架|`403`|
|作者本人 + 已被技能级下架|`200`（否则作者无法自查自己传过什么）|
|技能不存在|`400 NOT_FOUND`|

  

### 5.3 返回参数

  

**成功：****`200 OK`**

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`owner`|string|作者身份标识|
|`slug`|string|技能短名|
|`displayName`|string|技能展示名|
|`summary`|string|技能简介|
|`visibility`|string|`PUBLIC` / `PRIVATE`|
|`hidden`|boolean|**是否已被技能级下架**。`true` 表示搜不到、非作者不可见不可下|
|`ownerDisplayName`|string|作者展示名（来源见 §9.3）|
|`downloadCount`|integer|该技能累计下载次数|
|`headlineVersion`|string\|null|**当前对外版本号**，即客户端默认应该下的那个版本|
|`publishedAt`|string\|null|`headlineVersion` 的发布时间|
|`versions`|array|全部版本列表，结构见下。客户端从中挑版本拼下载 URL|

  

`versions[]` 元素：

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`version`|string|版本号，直接用于拼下载 URL|
|`status`|string|版本状态。枚举有 8 个值，本平台**实际只会出现** **`PUBLISHED`** **与** **`YANKED`**|
|`fileCount`|integer|该版本的文件数|
|`totalSize`|integer|该版本的总字节数|
|`downloadReady`|boolean|资源是否已就绪。本平台恒等于「已发布」|
|`publishedAt`|string\|null|发布时间|
|`yankedAt`|string\|null|**版本级下架时间。非** **`null`** **即该版本永远不可下载**|
|`isHeadline`|boolean|是否是 `headlineVersion`，便于客户端标注「最新版」|

  

**错误**：`400 NOT_FOUND`（技能不存在）、`403`（PRIVATE 或已下架且非作者）。

## 6. 下载

  

### 6.1 功能

  

按版本号取一个 zip 字节流。对调用方（智能体）来说，这个平台就是「带版本管理的文件服务」：给它 `owner/slug/version`，它拿到一个 zip 就能跑。

  

```Plain
GET /api/skills/alice/weather/versions/1.2.0/download
```

  

**只有这一个下载入口。** 原平台的「下最新版」与「按标签下载」都砍掉了：前者原文自己说前端从不调，后者属于标签系统不在范围内（27 §5.2）。要下最新版，先从详情的 `headlineVersion` 拿到版本号再拼 URL。

  

### 6.2 请求参数

  

**路径参数**（无查询参数）：

  

|   |   |   |   |
|---|---|---|---|
|参数|类型|必填|作用|
|`owner`|string|是|作者身份标识|
|`slug`|string|是|技能短名|
|`version`|string|是|**要下载的确切版本号**，取自详情响应的 `versions[].version`|

  

### 6.3 唯一的下载门禁

  

全平台只有这一处下载判定，五个条件全部满足才放行：

  

```Plain
技能未被下架（hidden=false）        否则 403（作者本人除外）
技能可见性不是 PRIVATE 或请求者是作者  否则 403
版本状态 == PUBLISHED               否则 400
download_ready == true              否则 400
yanked_at 为空（版本未被下架）        否则 400
```

  

交叉表（可直接当测试用例集，来源 29 §8）：

  

|   |   |   |   |   |
|---|---|---|---|---|
|请求者|PUBLIC 已发布|PRIVATE 已发布|技能已下架|版本已下架|
|匿名|✅ 200|❌ 403|❌ 403|❌ 400|
|其他已登录用户|✅ 200|❌ 403|❌ 403|❌ 400|
|**技能作者**|✅ 200|✅ 200|✅ 200|❌ 400|
|平台管理员|✅ 200|❌ 403|❌ 403|❌ 400|

  

两点值得注意：

  

- **平台管理员在下载门禁上不比普通用户多任何权限。** 本平台授权模型只有「是否为作者」，没有平台角色。
    
- **技能级下架对作者本人不生效**（否则作者无法自查），但**版本级下架对所有人不可逆，包括作者**。
    
      
    

### 6.4 返回参数

  

**成功有两种出口，行为等价，调用方无需区分**：

  

**出口 A：****`200 OK`****，服务端流式转发**

  

|   |   |   |
|---|---|---|
|响应头|值|作用|
|`Content-Type`|`application/zip`|文件类型|
|`Content-Disposition`|`attachment; filename="{slug}-{version}.zip"`|建议的保存文件名|
|`Content-Length`|字节数|总大小（流式生成时可能缺省）|

  

**出口 B：****`302 Found`****，客户端直连对象存储**

  

|   |   |   |
|---|---|---|
|响应头|值|作用|
|`Location`|预签名 URL|有效期 **10 分钟**，过期需重新请求本接口|

  

**响应体是 zip 字节流，没有 JSON 结构。** 走到哪个出口由服务端决定：本地存储后端下预签名 URL 恒为空，**一定是流式转发**；S3 / MinIO 且请求为 HTTPS 时才可能 302。

  

**错误**：`400`（版本不存在 / 未发布 / 未就绪 / 已下架）、`403`（PRIVATE 或技能已下架且非作者）、`429`。

  

### 6.5 计数行为

  

下载计数**在字节流出去之前**完成，两张表各 +1（`skill.download_count`、`skill_version_stats`），合并为一个事务。

  

由此产生的语义，调用方必须知道：

  

|   |   |
|---|---|
|场景|是否计数|
|正常下载完成|✅|
|拿到 302 后未真正下载|✅ **会计数**|
|流传输中途断开|✅ **会计数**|
|未通过门禁的请求（400 / 403）|❌ 不计数|

  

**没有幂等键，可以被刷。** 这是自觉接受的取舍（29 §6）。

  

### 6.6 降级路径

  

如果对象存储里的整包 `packages/{skillId}/{versionId}/bundle.zip` 不存在（被误删等），服务端会读 `skill_file` 登记条、探测单个文件是否还在、在内存里现打一个 zip 返回。

  

**这个临时包不会写回对象存储**，所以每次请求都会重新读一遍、重新打一遍。对调用方透明，但这类请求会明显更慢。

## 7. 版本下架

  

### 7.1 功能

  

**让某个版本从此不能下载。** 发布是单向的，这是唯一的补救手段 —— 传了个带密钥或恶意脚本的包，靠它收回来（28 §5.5）。

  

```Plain
DELETE /api/skills/alice/weather/versions/1.2.0
X-User-Id: alice
```

  

### 7.2 请求参数

  

**路径参数**（无请求体、无查询参数）：

  

|   |   |   |   |
|---|---|---|---|
|参数|类型|必填|作用|
|`owner`|string|是|作者身份标识。**必须与身份头一致，否则 403**|
|`slug`|string|是|技能短名|
|`version`|string|是|要下架的版本号|

  

### 7.3 返回参数

  

**成功：****`200 OK`**

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`owner`|string|作者身份标识|
|`slug`|string|技能短名|
|`version`|string|被下架的版本号|
|`status`|string|恒为 `YANKED`|
|`yankedAt`|string|下架时间（ISO 8601 UTC）|

  

**错误**：`400 NOT_FOUND`（技能或版本不存在）、`401`（未登录）、`403`（非作者）、`429`。

  

### 7.4 不可逆

  

**版本级下架不可撤销，对所有人（含作者本人）永久生效。** 之后就这个版本而言，下载恒返回 400，详情里该版本的 `yankedAt` 非空、`status` 为 `YANKED`。

  

它是「已分发内容可收回」的唯一硬手段，所以不做恢复。技能级下架本可恢复（29 §7），但本版本不提供恢复接口，**两级下架最终都是不可逆的**（见 §8.5）。

## 8. 技能下架

  

### 8.1 功能

  

**把整个技能从公共视野里摘掉**：搜不到、非作者看详情 403、非作者下载 403。作用于整个技能，用 `hidden` 布尔位实现。

  

```Plain
DELETE /api/skills/alice/weather
X-User-Id: alice
```

  

### 8.2 请求参数

  

**路径参数**（无请求体、无查询参数）：

  

|   |   |   |   |
|---|---|---|---|
|参数|类型|必填|作用|
|`owner`|string|是|作者身份标识。**必须与身份头一致，否则 403**|
|`slug`|string|是|技能短名|

  

### 8.3 返回参数

  

**成功：****`200 OK`**

  

|   |   |   |
|---|---|---|
|字段|类型|作用|
|`owner`|string|作者身份标识|
|`slug`|string|技能短名|
|`hidden`|boolean|恒为 `true`，表示已下架|
|`updatedAt`|string|下架时间（ISO 8601 UTC）|

  

**错误**：`400 NOT_FOUND`（技能不存在）、`401`（未登录）、`403`（非作者）、`429`。

  

### 8.4 效果

  

|   |   |
|---|---|
|接口|下架后行为|
|搜索|搜不到，**包括作者本人**（`owner=me` 也列不出）|
|详情|非作者 `403`；作者仍 `200`，响应里 `hidden = true`|
|下载|非作者 `403`；**作者本人仍可下载**|

  

**下架不删数据** —— 版本、文件、对象存储里的字节都还在。
